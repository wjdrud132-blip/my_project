선행조건 AIO_002, 초기·임시 비밀번호 변경 대상임
관련 액터 간호사
1. 초기·임시 비밀번호로 로그인하면 비밀번호 변경 화면이 표시된
다.
2. 사용자가 초기·임시 비밀번호를 입력하고 ‘비밀번호 확인’을 눌
러 일치 여부를 확인한다.
3. 기존 비밀번호와 다른 새 비밀번호와 확인값을 입력한다. 새 비
이벤트 흐름 밀번호는 영문·숫자를 포함한 8자 이상으로 입력한다.
4. ‘비밀번호 변경하기’를 누르면 시스템이 입력값을 검증하고 새
비밀번호를 저장한다.
5. 변경 완료 안내를 확인하면 병동 대시보드로 이동한다.
예외 흐름 : 미입력, 비밀번호 불일치, 입력 조건 미충족 또는 기
존 비밀번호와 동일한 경우 안내 후 재입력하도록 한다.
새 비밀번호가 저장되고 변경 완료 안내를 확인하여 병동 대시보
종료조건
드로 이동했을 때 종료된다.

유스케이스 이름 간호사 계정 생성
유스케이스 ID AIO_008
관련 요구사항 FR-AD-203, FR-AD-204
우선순위 상
선행조건 AIO_002, 관리자 권한 보유
관련 액터 관리자
1. 관리자가 간호사 관리 화면에서 ‘계정 생성’ 버튼을 선택한다.
2. 시스템은 이름, 아이디, 전화번호 입력란과 담당 병동 선택란이
있는 간호사 계정 생성 팝업을 표시한다.
3. 관리자가 간호사 이름, 아이디, 전화번호를 입력하고 담당
병동을 선택한 후 ‘계정 생성’ 버튼을 선택한다.
4. 시스템은 필수 입력 여부, 전화번호 형식, 아이디 및 전화번호
중복 여부를 확인한다.
5. 입력값이 올바르면 시스템은 임시 비밀번호를 발급하여 간호사
계정을 생성한다.
이벤트 흐름
6. 시스템은 간호사 목록을 갱신하고 생성 완료 팝업에 이름,
아이디, 마스킹된 전화번호, 담당 병동, 임시 비밀번호를 표시한다.
7. 관리자가 로그인 정보를 확인하고 ‘확인’ 버튼을 눌러 팝업을
닫는다.
대체 흐름: 계정 생성 전에 ‘취소’ 버튼을 선택하면 계정을
생성하지 않고 팝업을 닫는다.
예외 흐름: 필수값 누락, 전화번호 형식 오류 또는 담당 병동
미선택 시 오류를 안내하고 다시 입력하도록 한다. 중복된
아이디는 아이디 입력란 아래에 안내한다. 계정 생성에 실패하면
오류 안내를 표시한다.
종료조건 계정 생성 후 완료 팝업을 닫거나, 생성 전 취소했을 때 종료된다.
